# Agent Note: 收窄成果操作入口

Status: implemented

## Problem

[成果预览](../feature/2026-09-26-add-html-svg-artifact-preview.md)让消息代码块和成果面板同时提供复制、源码、下载等操作。长 SVG 在桌面双栏查看时，两边重复的按钮和标题占据了阅读空间。

## Decision

可预览成果在消息代码块的单行顶栏只显示语言和“打开预览”；其余代码块（包括无效的显式 SVG）仍显示语言和“复制代码”。面板去掉独立的成果类型/标题行，把关闭按钮移到复制、下载旁边；只在 HTML 面板保留与运行隔离相关的底部提示，SVG 面板不再重复解释图片上下文。成果源码、复制和下载仍在面板操作栏中，预览隔离方式不变。

## Alternatives considered

- **保留消息中的快捷操作**：少一次点击即可复制或下载，但同屏打开面板时重复控件明显，代码阅读空间也被两行顶栏压缩。
- **删掉面板中的源码与文件操作**：消息侧入口可以承担这些动作，但面板全屏时无法同时看见消息入口，且预览/源码切换需要面板内完成。

## Consequences

消息代码块顶栏和面板操作栏各占一行，按钮职责更清楚。用户若要复制或下载可预览成果，需要先打开面板；无效 SVG 没有预览入口，但仍可在原代码块中复制。HTML 的外部请求限制仍在面板底部提示，SVG 的图片环境区别仍由安全文档记录。
