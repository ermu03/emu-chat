# 部署、安全与渲染策略

状态：MVP 已批准实现基线
更新时间：2026-09-19

## 1. 首发部署边界

```text
可信 LAN 浏览器
    -> http://<server-lan-ip>:3000 emu-chat（0.0.0.0）
    -> http://127.0.0.1:8642 Hermes（只在服务器本机）
```

MVP 明确不实现：emu-chat 登录、用户账户、HTTPS、反向代理、公网访问保护或多用户隔离。部署者接受这是一套开发/自用、可信局域网方案；任何能访问该端口的 LAN 客户端都可能操作 Hermes Agent。

页面顶栏/关于区必须显示非阻塞警告：“当前为无认证 HTTP 模式，仅用于可信局域网；请勿暴露到公网。”

不得因为文档写明风险就把 Hermes `8642` 绑定到 LAN。Hermes 仍保持 `127.0.0.1`，浏览器只能通过 emu-chat adapter 间接访问。

## 2. 固定环境配置

MVP 只支持服务启动时的环境配置，不提供浏览器设置 Hermes URL/key：

| 变量 | 默认/要求 | 说明 |
| --- | --- | --- |
| `EMU_CHAT_HOST` | `0.0.0.0` | Fastify bind host |
| `EMU_CHAT_PORT` | `3000` | HTTP 端口 |
| `EMU_CHAT_DATA_DIR` | `./data` | emu-chat SQLite 及运行数据目录 |
| `HERMES_BASE_URL` | `http://127.0.0.1:8642` | 只在服务端使用；必须是启动配置 |
| `HERMES_API_KEY` | 必填 | Hermes `API_SERVER_KEY` 的值，不写数据库 |
| `LOG_LEVEL` | `info` | `trace|debug|info|warn|error|fatal` |

启动时缺少/空 `HERMES_API_KEY` 不退出 Web 服务，但 status 为 `auth_failed/config_error`，所有 Hermes mutation 禁用，方便用户看到诊断页面。不得把 key 输出到错误或日志。

## 3. MVP 的安全承诺和不承诺

仍必须做到：

- Hermes key/provider key/环境变量不进入前端 bundle、API 响应、SQLite 或日志；
- 不启用 CORS 响应头，不提供 JSONP；mutation 只接受 `application/json`；
- 不接受每请求上游 URL、任意文件路径或通用 HTTP/file proxy；
- 所有输入做 schema/长度校验，所有 SQL 参数化；
- 错误响应无堆栈、绝对路径、原始命令或未经脱敏工具正文；
- 模型/Hermes 内容按不可信数据安全渲染。

明确不承诺：

- LAN 客户端身份、CSRF/DNS rebinding 防护、请求签名或访问控制；
- 传输机密性/完整性；
- 恶意同网段客户端隔离；
- 反向代理 header 信任、公网限流或互联网攻击防护。

后续加入认证/HTTPS 时必须另立 ADR，不能在本 MVP 中留下半成品登录或 cookie 逻辑。

## 4. HTTP 与 PWA 边界

普通 LAN IP 的 HTTP 通常不是浏览器 secure context，因此：

- 响应式 Web UI、REST 和 SSE 是 P0，必须始终可用；
- manifest 和图标可以提供；
- 只有 `window.isSecureContext && 'serviceWorker' in navigator` 时才尝试注册 Service Worker；
- 不满足条件时不注册、不反复报错，并在设置/关于区显示“当前 HTTP 环境不保证安装型 PWA”；
- Service Worker 即使可用，也只缓存版本化 app shell；`/api/*` 和 SSE 必须 network-only；
- 不承诺离线历史、离线草稿跨设备或离线发送。

检测到浏览器网络断开时保留本地页面和已存草稿，但历史区标记离线，不把旧 React state 伪装为最新 Hermes 历史。

## 5. Hermes 工具风险提示

当前 Hermes `runtime.mode=server_agent`、`tool_execution=server`。工具可能在服务器上执行 terminal、文件和浏览器操作。

emu-chat 必须：

- 在状态/approval 区说明“工具运行在 Hermes 服务器”；
- 不把 Markdown sanitizer 称为工具沙箱；
- 不自动批准 approval；
- 只提供 `once` 与 `deny`；
- 将工具命令、arguments、preview、result 当作可能敏感的不可信文本；
- 不把这些字段写访问日志或错误 telemetry。

## 6. 输出渲染管线

固定采用 AST 渲染，不允许手写正则替代 sanitizer：

1. `react-markdown` 解析 CommonMark；
2. `remark-gfm` 支持表格、task list、删除线；
3. `remark-math` + `rehype-katex` 渲染数学；
4. `rehype-sanitize` 使用仓库内显式 schema；
5. 代码块高亮只处理文本，不执行代码；
6. 所有外链添加 `rel="noreferrer noopener"`，新窗口行为统一；
7. 禁止 raw HTML、`script/style/iframe/object/embed/form` 和事件属性；
8. 禁止 `javascript:`、`vbscript:` 和非批准 data URL；MVP 不渲染远程/内联消息图片，图片/附件属于 P1；
9. KaTeX CSS 为静态构建资源，不从 CDN 注入脚本。

流式 delta 先以安全纯文本或可容错 Markdown 渲染；不得把不完整文本传入 `dangerouslySetInnerHTML`。终态后以 Hermes messages 的持久化内容重新渲染。

## 7. 服务端限制

精确限制固定在共享 schema 中：

| 项目 | MVP 上限 |
| --- | --- |
| 用户输入/草稿/queue payload | 64 KiB UTF-8 |
| session title | 200 Unicode 字符 |
| 单个 tag | 40 字符 |
| 每 conversation tags | 20 个 |
| 每 conversation 中 state 非 `done|cancelled` 的 queue records | 100 个 |
| session list page | 100（上游最大 200） |
| messages page | 200（上游最大 500） |
| 浏览器 SSE connections | 全局 20、每 run 5 |
| 本地 event ring | 512 events 或 1 MiB/run |
| JSON body | 128 KiB |

超限返回 `PAYLOAD_TOO_LARGE` 或 `INVALID_REQUEST`，不截断后静默发送。tool preview 展示层可截断，但必须标明“预览”。

上游连接超时固定值：普通读 10 秒、run submit 30 秒；create/fork/update/delete/stop/approval 等所有其他上游 mutation 为 10 秒。上游 SSE 首次响应头为 10 秒，连接后若连续 30 秒没有收到任何 event 或 keepalive 字节，则 abort、标记 gap 并串行重连。超时只改变状态，不证明请求未到达。

## 8. 日志规则

结构化日志只允许：request id、operation/local run id、上游 HTTP status、稳定错误码、耗时、事件名和计数。

禁止记录：

- Authorization/cookie/所有 key；
- 用户输入、draft、message content、reasoning、tool args/result/preview；
- 完整请求/响应 body；
- 环境变量和数据库内容；
- 浏览器可见错误中的服务器绝对路径/堆栈。

session id/run id 可用于本机诊断，但 debug 之外应优先记录截短/hash；绝不能把 id 当秘密安全边界。

## 9. 文件、权限与备份

- `EMU_CHAT_DATA_DIR` 不在静态资源目录内；启动时创建为 0700，数据库和备份目标为 0600（平台允许时）。
- emu-chat DB 只需备份 schema、草稿、队列、run control 和 UI metadata；它不是历史备份。
- Hermes `state.db`、memories、sessions/files 由 Hermes 运维策略独立备份。
- 删除 emu-chat DB 不得删除 Hermes 数据；重建后只能重新发现当前 Hermes list 可见范围，不能发现 archived 全集。
- migration 失败时服务进入 `incompatible`/只读诊断状态，不自动删库重建。

## 10. 连接状态投影

后端对浏览器只返回：

`checking | healthy | degraded | unavailable | auth_failed | incompatible | config_error`

允许字段：Hermes 版本摘要、缺失 capability 名称、最近检查时间、安全重试建议、`lan_http_warning=true`、`pwa_secure_context_required=true`。禁止返回 PID、路径、环境、key、provider URL 或堆栈。
